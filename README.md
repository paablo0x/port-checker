# Python Port Checker

**Python · Socket Programming · Network Reconnaissance**

A simple Python tool for checking TCP port availability using socket connections.

## Features
- Checks whether a TCP port is open or closed
- Accepts a host and port through command-line arguments
- Uses connection timeouts to avoid hanging

## Usage

```bash
python port_checker.py 127.0.0.1 80
```
